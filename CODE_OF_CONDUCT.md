# Contributor Code of Conduct

We aim for a welcoming, professional and inclusive open contributor community.

- Be respectful, constructive and precise in technical discussion.
- Discuss ideas and evidence without personal attacks or harassment.
- Respect differing experience levels, backgrounds and viewpoints.
- Protect user privacy and responsible security disclosure.
- Review pull requests with concrete feedback and patience.

Maintainers may hide or remove abusive content or restrict participation where necessary. Report conduct concerns privately through the repository maintainer's GitHub profile or a designated private contact once published.

This document describes a collaboration standard; it does not imply that the source code is currently offered under an open-source license.
