# Competitive Benchmarks

This is a **product benchmark**, not a claim about competitor market shares or exact current tool counts. Features/pricing change: validate with current official product documentation before implementation.

| Competitor | Learn from | What to test ourselves against |
| --- | --- | --- |
| Adobe Acrobat | Native content editing, OCR, redaction, forms, accessibility, digital signatures, comparison and workflows | Edit fidelity, security, advanced features |
| Sejda | Direct text editing, find/replace, links, forms, split variants, Bates, page operations | Editor usability, coverage and speed |
| iLovePDF | Fast, discoverable merge/split/conversion/compression/repair/AI workflows | Ease and breadth of tools |
| Smallpdf | Simplified funnels and polished web UX | Upload-to-output completion experience |
| ONLYOFFICE | Document/PDF editing and collaboration | Evaluate editor engine only with proper license |
| Other proprietary editor SDKs | Nutrient, Apryse and comparable products | Native content accuracy, SDK cost and lock-in |

## Mandatory comparison protocol
1. Create a synthetic document set: text-heavy, scanned, multilingual, tables, complex fonts, rotated pages, forms, bookmarks, encrypted, damaged, huge, signed and tagged PDFs.
2. Record each competitor's observable behavior **without copying** proprietary implementation.
3. Measure task time, steps, output validity, layout differences, text extraction, searchability, annotations/form survival, privacy, error handling and accessibility.
4. Document screenshots only where legally usable; never redistribute third-party product assets casually.
5. Record results and dates. “Not tested” is not “missing.”

## Our differentiation thesis
Leading competitors may have tool breadth, editor depth or simplicity; our differentiator is a continuous workspace with accurate, privacy-preserving multi-step workflows and transparent testing.
